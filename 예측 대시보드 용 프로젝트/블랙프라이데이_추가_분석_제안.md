# 블랙프라이데이 심화 분석 제안 (Medium EDA 후 추가)

Medium 글 [An Exploratory Data Analysis on Olist E-commerce Dataset](https://medium.com/@tobye070/the-exploratory-data-analysis-on-olist-e-commerce-dataset-cbddd09d936c)에서 이미 다룬 내용과, **추가로 고려해볼 분석**을 정리했습니다.  
말씀하신 아이디어를 **Olist 데이터로 할 수 있는 것 / 한계**로 나누고, 그 위에 **추가 제안**을 붙였습니다.

---

## 1. Medium 글에서 이미 다룬 내용 (참고)

- **Black Friday 효과**: 2017년 47주(11/24 근처) 주문 급증, 전주 대비 2배 이상
- 총 매출·주문 시계열, 분기별 추이, 인기 카테고리(bed_bath_table), AOV·결제수단·지역
- 재구매 고객 비중(~6%), 리텐션 낮음, 취소율(~0.63%), 리뷰·평점과 매출
- 주별/연도별 활성 셀러, 카테고리별 성장률(computer accessories 196%), 지역별 고객 밀도·리텐션

## 2. 말씀하신 아이디어 → 구체 분석 제안 (Olist 데이터 기준)

### 2.1 BF에 구매한 사람: 신규 vs 재방문

| 분석 내용 | 데이터로 가능한 것 | 비고 |
|-----------|-------------------|------|
| **신규 vs 재방문** | BF 해당 주(11월 넷째 주)에 **첫 주문**인 고객 vs **그 전에 이미 주문 이력**이 있는 고객 비율 | `customer_unique_id` + `order_purchase_timestamp`로 “BF주 이전 최초 주문일” 존재 여부로 구분 |
| **수치 제시** | BF주 구매자 중 신규 비율(%), 재방문 비율(%), 신규/재방문별 주문 건수·매출 | 연도별(2016/2017/2018 BF) 나누면 “BF가 신규 유입에 기여했는지” 추이 가능 |

**추가 제안**: BF 주 **직전 4주 대비** BF 주의 신규 비율이 올라가는지 비교 → “BF가 신규 끌어오는 효과가 있는지” 검증.

---

### 2.2 BF 때 주로 무엇을 구매했을까

| 분석 내용 | 데이터로 가능한 것 | 비고 |
|-----------|-------------------|------|
| **카테고리별 매출·주문** | BF 주에 한정해 `product_category_name`별 매출, 주문 건수, 비중(%) | 이미 `Trends_성장카테고리_블랙프라이데이_전략.ipynb`에서 11월/BF주 비중 계산 가능 |
| **세부 상품 TOP N** | BF 주 **상품( product_id )**별 판매 건수·매출 TOP 20 | order_items + products + orders(날짜 필터) |
| **연도별 비교** | 2016 vs 2017 vs 2018 BF 주 카테고리 순위 변화 | “매년 BF 때 인기 카테고리가 바뀌는지” 확인 |

**추가 제안**: **객단가 구간**(예: 50 미만, 50~150, 150~500)별 BF 주 매출 비중 → “저가 타깃이었는지, 고가 프로모션도 먹혔는지” 요약.

---

### 2.3 BF 매출액, 객단가, 가장 많이 팔린 조합

| 분석 내용 | 데이터로 가능한 것 | 비고 |
|-----------|-------------------|------|
| **BF 주 매출·객단가** | BF 해당 주 **총 매출**, **주문 수**, **객단가(AOV)** = 총매출/주문수 | 연도별로 나누면 2016/2017/2018 BF 수치 비교 |
| **같이 가장 많이 팔린 조합** | BF 주에 한정해 **같은 주문 안**에서 함께 산 **카테고리 쌍** 빈도 (08-F와 동일 로직, `is_bf_week` 필터만 추가) | “BF 때 번들/크로스셀 후보” 도출 |
| **상품 쌍(선택)** | 주문 단위로 같은 주문에 함께 등장한 **product_id 쌍** 빈도 TOP N | 데이터 크기 커지면 샘플링 또는 상위 카테고리만 |

**추가 제안**: BF 주 vs **비BF 주(같은 연도)** 평균 객단가 비교 → “BF 때 객단가가 올랐는지/내렸는지” 수치로 제시.

---

### 2.4 시장 검색 관심(검색량) vs Olist 실제 구매

| 분석 내용 | 데이터로 가능한 것 | 비고 |
|-----------|-------------------|------|
| **검색량이 높아진 제품류** | Google Trends BR 2016–2018에서 **BF 주 vs 비BF 주** 평균 interest 비교 → BF 시 상승한 키워드 TOP N | 02번·Trends 전략 노트북으로 수집 가능 |
| **관심도가 Olist 구매로 이어졌는지** | **키워드(카테고리)**와 **Olist 카테고리** 매칭 후, BF 주 해당 카테고리 **매출·주문 성장률** vs **Trends interest 성장률** 상관/순위 비교 | “검색 많이 오른 카테고리 = Olist에서도 많이 팔렸는지” 표·산점도 |
| **수치 예시** | 카테고리별 “Trends BF lift”, “Olist BF주 매출 전년동기 대비 성장률” 한 테이블에 정리 | 전략 노트북에서 확장 가능 |

**추가 제안**: Trends에서 **지속 성장**한 카테고리 중, BF 주에 **Olist 매출도 함께 큰** 카테고리 → “내년 BF 핵심 공략 후보” 리스트.

---

### 2.5 BF 때 방문한 사람들의 리텐션

| 분석 내용 | 데이터로 가능한 것 | 비고 |
|-----------|-------------------|------|
| **리텐션 정의** | “BF 주에 첫 구매한 고객” 중 **이후 N개월(또는 N주) 안에 재구매**한 비율 | 예: 3개월 내 재구매율, 6개월 내 재구매율 |
| **비교 그룹** | **비BF 주에 첫 구매한 고객**의 동일 기간 재구매율과 비교 | “BF로 유입된 고객이 더 잘 남는지/덜 남는지” |
| **연도별** | 2016 BF 코호트, 2017 BF 코호트, 2018 BF 코호트 각각 리텐션 곡선 | 06-D 코호트 로직을 “BF주 첫 구매”로만 잘라서 적용 |

**추가 제안**: BF 코호트를 **신규 vs 재방문**으로 나눠, **신규 BF 유입**의 리텐션이 **재방문 BF 구매자**보다 낮은지 비교 → 로열티 프로그램/재방문 유도 타깃 제안.

---

### 2.6 내년 블랙프라이데이 준비 방향

| 분석 내용 | 데이터로 가능한 것 | 비고 |
|-----------|-------------------|------|
| **재고·노출** | BF 시 매출·주문 비중이 높았던 카테고리 + Trends BF lift 높은 키워드 → **재고·배너·검색광고** 우선순위 리스트 | 전략 노트북 6·7절과 동일 방향 |
| **가격·프로모션** | BF 주 vs 비BF 주 **카테고리별 평균 단가** 비교 → “BF 때 평균 단가가 떨어진 카테고리” = 할인 효과 컸을 가능성 | order_items.price 기준 |
| **다음 BF 체크리스트** | 1) 지속 성장 카테고리 2) BF 반응 큰 카테고리 3) 검색 관심 상승 키워드 4) BF 코호트 리텐션 낮은 세그먼트(재유입 캠페인) | 마크다운/노트 한 장 요약 |

**추가 제안**: **지역( state )**별 BF 주 매출 비중 → “내년 BF 때 지역별 재고·배송·광고” 우선순위.

---

### 2.7 BF 때 유독 많이 구매한 사람의 특징 (지역, 쿠폰, 가격 등)

| 분석 내용 | 데이터로 가능한 것 | 한계 |
|-----------|-------------------|------|
| **지역** | BF 주 구매자의 **customer_state** 분포, BF 주 매출 비중이 높은 state TOP 5~10 | geolocation·customers 연계 가능 |
| **결제 수단** | BF 주에 **voucher** 사용 비율 vs 비BF 주 비교 | “쿠폰/바우처”는 **결제 수단이 voucher**인 경우만 추정 가능 (실제 쿠폰 여부는 데이터 없음) |
| **평균 단가 vs 평소** | BF 주 **카테고리별 평균 price** vs 같은 연도 비BF 주 평균 → “BF 때 더 저렴해진 카테고리” | 할인 여부는 직접 컬럼 없어 **가격 하락**으로 간접 추정 |
| **BF 집중 구매자** | BF 주 매출이 **해당 고객 연간 매출에서 차지하는 비중**이 높은 고객(예: 상위 20%) → 이들의 **state, 결제수단, 주로 산 카테고리** 프로파일 | “BF에만 몰아서 사는 사람” vs “평소에도 자주 사는 사람” 구분 가능 |

**데이터 한계**:  
- **쿠폰/할인 여부** 컬럼은 없음. **voucher** 결제 비율, **BF 주 평균 단가 vs 비BF** 로 간접만 가능.  
- **마케팅 채널**(어디서 유입됐는지) 데이터 없음.

**추가 제안**:  
- BF 주 **1인당 주문 수·1인당 매출** 분포(히스토그램 또는 구간별 비율) → “소수 고객이 BF 매출을 끌어올렸는지” 파레토 확인.  
- **첫 구매가 BF인 고객** vs **이미 재구매자**의 BF 주 객단가 비교 → “신규는 작은 구매, 재방문은 큰 구매”인지 여부.

---

### 2.8 이들에게 어떤 마케팅·쿠폰을 적용했다면 좋았을까

| 분석 내용 | 데이터로 가능한 것 | 한계 |
|-----------|-------------------|------|
| **역발상 제안** | BF 코호트 **리텐션이 낮은** 세그먼트(예: 신규·저객단가) → “재방문 유도 쿠폰·이메일” 후보 | 실제 A/B 테스트 데이터 없어 **가설 수준** 제안만 가능 |
| **고객 가치별** | BF 시 **고객별 LTV(또는 연간 매출)** 상위 20% vs 하위 80% → 상위 20%는 “VIP 보상·얼리액세스”, 하위는 “재구매 쿠폰” 등 **역할 나누기** | RFM·코호트 결과와 결합 |
| **결제 수단** | BF 주 **voucher** 비율이 높으면 “다음 BF에도 voucher 프로모션” 강화 제안 | 인과는 데이터로 입증 불가, 제안만 |

**데이터 한계**:  
- **실제 쿠폰/마케팅 노출 이력**이 없어 “이걸 했으면 더 좋았을 것”은 **인사이트·가설**로만 정리 가능.

**추가 제안**:  
- **BF 이후 N개월 내 재구매한 고객** vs **재구매 안 한 고객**의 BF 주 **리뷰 점수·배송 만족도** 비교 → “만족도가 재구매로 이어졌는지” 보여주고, “만족한 BF 고객에게 재방문 쿠폰” 같은 가설 제안.

## 3. Medium 글 대비 추가로 고려할 만한 분석 (종합)

아래는 글에서 덜 다뤘거나, 말씀하신 주제와 맞물려 **추가로** 해보면 좋은 것들입니다.

1. **BF 주 정의 통일**  
   - 11월 넷째 주(금요일 기준)로 고정 후, **주 단위**로 모든 지표 집계 (매출, 주문 수, 신규/재방문 비율, 카테고리·지역·결제수단).

2. **BF 전용 코호트**  
   - “BF 주에 첫 구매” 코호트만 따로 두고, **경과 월/주별 재구매율·ARPU** 계산 → 06-D 코호트를 BF 코호트로 한 번 더 돌리기.

3. **신규 vs 재방문 BF 구매자 프로파일**  
   - BF 주 구매자 중 신규/재방문별 **state, 결제수단, 카테고리, 객단가** 분포 비교 표·차트.

4. **Trends ↔ Olist 매칭 테이블**  
   - 키워드(카테고리)별 **Trends BF lift**와 **Olist BF 주 매출·성장률** 한 테이블에 정리 → “검색 관심 = 구매로 이어졌는지” 시각화(산점도·순위).

5. **BF 시 “저렴해진” 카테고리**  
   - 카테고리별 BF 주 평균 단가 vs 비BF 주 평균 단가, **차이·비율** 컬럼 추가 → 할인 효과 추정.

6. **BF 집중 구매자(heavy BF buyer) 프로파일**  
   - BF 주 매출이 해당 고객 연간에서 차지하는 비중 상위 20% 고객의 **지역·결제·카테고리·객단가** 요약.

7. **내년 BF 체크리스트 문서화**  
   - 재고·노출·검색광고·지역·리텐션·가격·마케팅 가설을 **한 페이지 체크리스트**로 정리 (마크다운 또는 노트북 마지막 셀).

## 5. 데이터 한계 요약

- **쿠폰/할인 사용 여부**: 컬럼 없음 → voucher 결제, BF vs 비BF 평균 단가로 **간접 추정**만 가능.  
- **마케팅 채널·노출**: 없음 → “어떤 채널이 좋았을까”는 **가설·추천** 수준만.  
- **실제 프로모션 기간**: 없음 → BF 주를 “이벤트 기간”으로 **가정**하고 분석.

이 제안서를 기준으로 **블랙프라이데이 전용 노트북**을 하나 두고, 위 분석들을 순서대로 셀 단위로 구현해 나가면 됩니다. 원하시면 “BF 전용 노트북”에 들어갈 **셀 목차(순서)**나 **쿼리/집계 스케치**도 정리해 드리겠습니다.
