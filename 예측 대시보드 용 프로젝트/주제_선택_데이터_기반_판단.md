# 블랙프라이데이 vs 연간 비교 — 데이터 확인 후 판단

Olist 실제 데이터로 **연도별·월별 커버리지**를 확인한 뒤, 두 주제 중 어떤 게 더 나은지 정리했습니다.

---

## 1. 데이터 요약

| 연도 | 주문 수 | 월 커버리지 | 비고 |
|------|---------|-------------|------|
| **2016** | **267건** | 9월 1건, **10월 265건**, 12월 1건 | 실질적으로 **10월 한 달**만 의미 있음 |
| **2017** | 43,428건 | **1~12월 전부** | 11월 7,289건(BF·11월 분석 가능) |
| **2018** | 52,783건 | **1~8월만** (9~12월 없음) | BF·크리스마스 등 **하반기 데이터 없음** |

- **11월(블랙프라이데이)**: 2017년만 있음. 2016·2018년 11월 데이터 없음.
- **2017년 1–8월 vs 2018년 1–8월** (동기간):  
  - 2017 1–8월: 주문 약 2.2만 건, 매출 약 347만 R$  
  - 2018 1–8월: 주문 약 5.3만 건, 매출 약 845만 R$  
  → **주문·매출 모두 약 2배 이상**으로 YoY 비교에 충분한 수준.

---

## 2. 주제별 데이터 적합성

### 블랙프라이데이 단일 주제

- **가능한 것**: 2017년 11월 한 번의 BF(및 11월 전체)에 대한  
  피크일·신규/재방문·리텐션·카테고리 TOP·Trends 매칭·결제 수단 등 **구성은 풍부**하게 만들 수 있음.
- **한계**:  
  - 2016·2018년 11월이 없어 **“연도별 BF 비교”**는 불가.  
  - “2017년 한 해 BF 심화 분석”으로 스토리가 **한정적**.

### 연간 비교 주제 (2016 vs 2017, 2017 vs 2018, 2018 대비)

- **“2016 대비 2017 무엇이 개선”**  
  - 2016은 10월 265건뿐이라 **연도 단위 비교**로 쓰기엔 데이터가 너무 약함.  
  - 가능한 건 “2016년 10월 vs 2017년 10월” 같은 **한 달 비교** 정도.

- **“2017 대비 2018 무엇이 바뀌었나”**  
  - **1–8월 동기간**이면 데이터 충분.  
  - 주문 수·매출·월별 추이·카테고리 시프트·지역·결제 수단 등 **풍부한 YoY 분석** 가능.  
  - “2배 성장”, “어떤 카테고리/지역이 성장했는지” 등 **명확한 스토리** 만들기 좋음.

- **“2018년에는 무엇에 대비해야 할까”**  
  - 2018년 9월 이후(9–12월, BF 포함) **데이터 없음** → 2018 BF·연말은 직접 측정 불가.  
  - 대신 **2017년 하반기·BF 패턴**과 **2018년 1–8월 성장**을 합쳐서  
    “2018 상반기 트렌드 + 2017 하반기 참고로 2018 하반기·BF 대비 전략”처럼 **전략 제안**으로 마무리하는 건 가능.

---

## 3. 결론: 어떤 주제가 더 나은가?

| 기준 | 블랙프라이데이 단일 | 연간 비교 (2017 vs 2018 등) |
|------|---------------------|-----------------------------|
| **데이터 양** | 2017년 11월만 있어 한정적 | 2017 전년·2018 1–8월로 **충분** |
| **스토리 폭** | “한 번의 이벤트 심화”에 그치기 쉬움 | “성장·변화·다음 해 대비”까지 **넓게** 잡기 좋음 |
| **인상** | EDA·이벤트 분석 위주 | **트렌드·YoY·전략**까지 보여주기 좋음 |

**추천**:  
- **포트폴리오 메인 스토리는 “연간 비교”**로 두는 쪽이 데이터와 스토리 모두 유리합니다.  
  - 예: **“2017 vs 2018 (1–8월) 무엇이 개선·바뀌었나 + 2018년에는 무엇에 대비할까”**  
- **블랙프라이데이**는  
  - “2017년 하반기·이벤트 사례”로 **한 섹션(또는 파트)**으로 넣거나,  
  - 별도 노트북을 유지하되 “연간 비교 노트북에서 2017 BF를 참고 이벤트로 언급”하는 식으로 **연간 스토리 안에 녹이는 구성**을 추천합니다.

즉, **연간 비교를 메인**, **BF는 보조(또는 2017 사례)**로 두는 게 더 낫습니다.

---

## 4. 구현 제안 (연간 비교 메인일 때)

1. **2017년 1–8월 vs 2018년 1–8월**  
   - 주문 수·매출·객단가, 월별 추이, **카테고리·지역·결제 수단** 구조 변화  
2. **무엇이 개선/바뀌었나**  
   - 성장한 카테고리, 성장한 지역, 리텐션·신규 비율 변화(같은 기간 기준) 등  
3. **2018년 대비 전략**  
   - 2017년 하반기(9–12월)·BF 패턴 요약 + 2018 상반기 트렌드 반영  
   - “2018 하반기·BF 때 재고·카테고리·지역별로 무엇에 대비할지” 체크리스트 형태로 정리  
4. **(선택)** 기존 블랙프라이데이 노트북을 “2017 BF 심화”로 유지하고, 연간 노트북에서 “자세한 BF 분석은 별도 노트북 참고”로 링크

이렇게 하면 **데이터에 맞게** “2016 대비 2017”은 보조로 두고, **“2017 대비 2018 + 2018 대비”**를 메인으로 가져가는 게 가장 무난합니다.
