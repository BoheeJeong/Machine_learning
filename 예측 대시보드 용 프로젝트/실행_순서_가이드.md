## 2. 요약

- **00번을 맨 처음 한 번만 실행**하면 됩니다. (이미 `data/`가 있으면 00은 건너뛰어도 됩니다.)
- **01번**은 “원본 로드” 연습용이라, 00으로 데이터 마트 만든 뒤라면 **안 돌려도** 03~09는 동작합니다.
- **02번**은 Google Trends 분석·블랙프라이데이 전략 노트북(10번, 블랙프라이데이_심화_분석)에서 **검색 관심도**를 쓸 때만 실행하면 됩니다.
- **03-A ~ 09-G(4~10번)** 는 **00 실행 후**라면 **순서 상관없이** 돌려도 됩니다. 서로 같은 `data/`만 읽고, 서로의 결과물에 의존하지 않습니다.
- **10번(Trends 전략)** 과 **블랙프라이데이_심화_분석.ipynb** 는 02에서 만든 Trends CSV가 있으면 더 풍부한 분석이 가능하고, 없어도 Olist만으로 실행 가능합니다.

---

## 3. 연도별 비교·블랙프라이데이까지 할 때

1. **00** 실행 → `data/` 확인  
2. **03-A ~ 09-G** 원하는 순서로 실행 (연도별 비교는 각 노트북에 연도 필터만 넣어서 사용)  
3. (선택) **02** 실행 → Trends CSV 생성  
4. (선택) **10**, **블랙프라이데이_심화_분석** 실행  

정리하면, **“1~10 순서대로 돌린다”**고 생각하시면 되고, **반드시 지켜야 할 것은 00 → 그 다음 03~09** 입니다. 01·02·10은 목적에 따라 선택하면 됩니다.
