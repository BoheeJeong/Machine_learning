# Tableau: 매출 입력 → PKL로 군집 예측 시각화

**“이 매출이면 어떤 군집에 들어갈까?”** 를 Tableau에서 파라미터로 입력하고, TabPy가 pkl 모델로 예측한 군집을 보여주는 대시보드 만드는 방법입니다.

---

## 1. 준비 (한 번만)

### 1) pkl 모델 있음
- `wholesale_cluster_model.pkl` 이 **Lab 05 폴더**에 있어야 합니다.
- 없으면: `python save_wholesale_cluster_model.py` 실행.

### 2) TabPy 서버 실행
- 명령 프롬프트 또는 터미널에서:
  ```bash
  cd "C:\Users\bohee\Documents\GitHub\Machine_learning\[LAB 05] 비지도 학습 - 구매 패턴 기반 고객 군집 분석과 페르소나 도출"
  tabpy
  ```
- `TabPy server is listening on port 9004` 같은 메시지가 나오면 성공. **이 창은 닫지 말고 둡니다.**

### 3) Tableau에서 TabPy 연결
- Tableau 메뉴: **연결** → **Analytics Extension에 연결**
- **TabPy** 선택 후:
  - **서버**: `localhost`
  - **포트**: `9004`
- **연결 테스트** 후 확인.

---

## 2. 파라미터 6개 만들기

**데이터** 패널 빈 곳 우클릭 → **파라미터 만들기** 로 아래 6개를 만듭니다.

| 파라미터 이름 | 데이터 유형 | 현재 값 | 범위(최소~최대) | 권장 범위(데이터 기준) |
|---------------|-------------|---------|------------------|-------------------------|
| `P_Fresh` | 부동소수점 | 10000 | 0 ~ 120000 | 3 ~ 112151 |
| `P_Milk` | 부동소수점 | 5000 | 0 ~ 80000 | 55 ~ 73498 |
| `P_Grocery` | 부동소수점 | 5000 | 0 ~ 100000 | 3 ~ 92780 |
| `P_Frozen` | 부동소수점 | 2000 | 0 ~ 65000 | 25 ~ 60869 |
| `P_Detergents_Paper` | 부동소수점 | 2000 | 0 ~ 45000 | 3 ~ 40827 |
| `P_Delicassen` | 부동소수점 | 1000 | 0 ~ 50000 | 3 ~ 47943 |

- **표시 형식**: 숫자(정수 또는 소수 둘째 자리 등 원하는 대로).
- 슬라이더로 조정할 거면 **범위**를 위처럼 넉넉히 두면 됩니다.

---

## 3. 계산 필드: “예측 군집” (TabPy + pkl 호출)

**계산 필드 만들기** → 이름: `예측 군집` (또는 `Predicted Cluster`)

**수식** (아래 한 줄이 아니라 여러 줄로 넣어도 됨):

```tableau
SCRIPT_INT(
  "
  import sys
  sys.path.append(r'C:\Users\bohee\Documents\GitHub\Machine_learning\[LAB 05] 비지도 학습 - 구매 패턴 기반 고객 군집 분석과 페르소나 도출')
  from tabpy_wholesale_cluster import get_cluster
  return get_cluster(_arg1, _arg2, _arg3, _arg4, _arg5, _arg6)
  ",
  [P_Fresh], [P_Milk], [P_Grocery], [P_Frozen], [P_Detergents_Paper], [P_Delicassen]
)
```

- `sys.path.append(...)` 안 경로를 **본인 PC의 Lab 05 폴더 실제 경로**로 바꿔주세요.
- `[P_Fresh]` 등은 방금 만든 **파라미터** 이름과 정확히 맞추면 됩니다.

저장 후, 데이터 패널에 **예측 군집** 측정값이 생깁니다.

---

## 4. 시각화 시트 만들기

### 시트 1: “매출 입력 → 예측 군집” 결과만 보기

1. **행** 선반에 **측정값 이름** 드래그  
   → **측정값** 을 **행**으로 이동해 “측정값 이름” / “측정값” 펼침.
2. **측정값 이름** 을 **필터**로 넣고, **예측 군집**만 선택 (다른 측정값 제거).
3. **표시**를 **텍스트 테이블**로 바꾸고, **마크**의 **텍스트**에 **측정값** 넣기.  
   → 이렇게 하면 “예측 군집” 하나만 나와서 숫자(0~4)가 보입니다.

**더 단순한 방법 (추천):**

1. **열** 선반에 **예측 군집** 드래그 (숫자 하나가 큰 글씨로 보임).
2. **행**은 비워 두어도 됩니다. (Tableau가 “전체” 한 번만 계산해 1개 값 표시.)
3. 값이 안 나오면 **행**에 **Customer ID**를 넣고, **필터**에서 **Customer ID = 1** 등 하나만 선택해 **1행만** 보이게 한 뒤, 그 시트에서 **예측 군집**을 **텍스트**나 **열**에 넣기.

→ 파라미터 6개(슬라이더)를 바꿀 때마다 **예측 군집** 숫자(0~4)가 갱신됩니다.

### 시트 2 (선택): 군집을 “군집 0”처럼 표시

계산 필드 하나 더 만들기:

- 이름: `예측 군집 라벨`
- 수식: `"군집 " + STR([예측 군집])`

시트에서 **예측 군집** 대신 **예측 군집 라벨**을 텍스트/제목에 넣으면 “군집 0”, “군집 1”처럼 보입니다.

---

## 5. 대시보드로 묶기

1. **대시보드** 새로 만든 뒤, 위 시트를 캔버스에 올립니다.
2. **매개 변수** 6개를 우측/좌측에 표시:
   - 각 파라미터 우클릭 → **매개 변수 표시** → 슬라이더로 표시.
3. 제목/설명 텍스트로 “매출(6개)을 입력하면 pkl 모델로 군집(0~4)을 예측합니다” 안내 추가.

이렇게 하면 **매출 6개를 슬라이더로 넣을 때마다 TabPy가 pkl을 써서 군집을 예측**하고, 그 값이 시트/대시보드에 바로 반영됩니다.

---

## 6. 문제 해결

| 증상 | 확인할 것 |
|------|------------|
| “예측 군집”이 비어 있거나 에러 | TabPy 서버가 실행 중인지, Tableau에서 Analytics Extension이 localhost:9004로 연결됐는지 확인. |
| “모듈/파일을 찾을 수 없음” | `sys.path.append(...)` 경로가 **Lab 05 폴더**(`tabpy_wholesale_cluster.py`, `wholesale_cluster_model.pkl` 있는 곳)인지 확인. 경로에 `[LAB 05]` 같은 대괄호가 있으면 그대로 두고, 본인 경로로만 수정. |
| 숫자가 안 바뀜 | 파라미터 이름이 수식의 `[P_Fresh]` 등과 정확히 같은지 확인. 시트를 **새로 고침** 하거나, 파라미터 값을 조금 바꿔서 다시 적용. |

이 구성을 따라가면 **PKL을 넣어서(연결해서), “매출이 ~~일 때 어떤 군집에 들어가는지” 예측하는 시각화**를 Tableau에서 만들 수 있습니다.
