## 과적합 판정 기준 (분류, hs_learning_cv 기준)

| 판정 | 의미 |
| --- | --- |
| ✅ 일반화 양호 | Train-CV gap ≤ 0.05 이고 CV 표준편차 ≤ 0.05 |
| ⚠ 과대적합 | Train-CV gap > 0.1 |
| ⚠ 과소적합 | Train·CV 둘 다 < 0.6 |
| ⚠ 데이터 부족 | CV 표준편차 > 0.1 |
| ⚠ 판단유보 | 위에 해당하지 않는 경우 |

## 사용 방법

1. **자동 생성**: 01~07 노트북에서 저장 셀까지 실행한 뒤, 터미널에서  
   `python 00-모델_요약_성능_과적합_리포트.py`  
   → `00-모델_요약_성능_과적합_리포트.csv` 와 이 `.md` 파일이 갱신됩니다.
2. **수동 정리**: 각 노트북의 성능 표·학습 곡선 표 값을 위 요약 표에 복사해 채우면 됩니다.
