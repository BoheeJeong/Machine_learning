# 태블로: 6개 품목 + Region 매개변수로 채널 예측 (4개 모델 전환)

TabPy가 이미 배포된 상태에서, **6개 품목 매출액**과 **Region**을 모두 **매개변수(슬라이더/드롭다운)**로 두고, **모델 선택 드롭다운**으로 XGBoost / RandomForest / CatBoost / LogisticRegression을 갈아끼워 쓰는 방법입니다.

---

## 1. 태블로 파라미터 만들기

### 1.1 6개 품목 매출액 (슬라이더 권장)

| 파라미터 이름 | 데이터 타입 | 예시 범위(최소–최대) | 현재값 예시 |
|---------------|-------------|----------------------|-------------|
| `Fresh` | Float / Integer | 0 ~ 100000 | 10000 |
| `Milk` | Float / Integer | 0 ~ 100000 | 5000 |
| `Grocery` | Float / Integer | 0 ~ 100000 | 80000 |
| `Frozen` | Float / Integer | 0 ~ 100000 | 3000 |
| `Detergents_Paper` | Float / Integer | 0 ~ 100000 | 20000 |
| `Delicassen` | Float / Integer | 0 ~ 100000 | 2000 |

- **만드는 법**: 우클릭 시트/데이터 패널 → **파라미터 만들기** → 이름·데이터 타입·범위 설정 후 **슬라이더** 표시로 두면 됩니다.

### 1.2 Region (드롭다운 권장)

| 파라미터 이름 | 데이터 타입 | 허용 값 |
|---------------|-------------|---------|
| `Region` | Integer 또는 String | 1, 2, 3 (또는 "1", "2", "3") |

- 채널 모델 학습 시 **1, 2, 3** 숫자로 쓰였으므로, **정수 1/2/3**으로 두는 것을 권장합니다.
- **목록**으로 1, 2, 3만 선택 가능하게 하면 됩니다.

### 1.3 모델 선택 (드롭다운)

| 파라미터 이름 | 데이터 타입 | 허용 값(문자열) |
|---------------|-------------|------------------|
| `Select ML Model` (또는 `ModelName`) | String | XGBoost, RandomForest, CatBoost, LogisticRegression |

- **목록**에서 위 4개 문자열이 **정확히** 이렇게 보이도록 설정합니다 (대소문자 일치 권장).

---

## 2. 계산된 필드 (TabPy 호출)

아래 두 계산된 필드는 **모두 파라미터만** 사용합니다. 데이터 소스의 행이 없어도, 파라미터 값만으로 1건 예측을 받을 수 있도록 합니다.

### 2.1 예측 채널 (0 또는 1) — SCRIPT_INT

**필드 이름(예)**: `예측 채널 (파라미터)`

```
SCRIPT_INT(
  "from tabpy_wholesale_cluster import get_channel; return get_channel(_arg1, _arg2, _arg3, _arg4, _arg5, _arg6, _arg7, _arg8)",
  [Fresh],           // _arg1
  [Milk],             // _arg2
  [Grocery],          // _arg3
  [Frozen],           // _arg4
  [Detergents_Paper], // _arg5
  [Delicassen],       // _arg6
  [Region],           // _arg7
  [Select ML Model]   // _arg8 → ModelName
)
```

- `[Fresh]`, `[Milk]` 등은 **위에서 만든 파라미터**를 그대로 넣으면 됩니다.
- `[Select ML Model]`은 **모델 선택 파라미터** 이름에 맞게 바꿔 주세요.

### 2.2 채널 1 확률 — SCRIPT_REAL

**필드 이름(예)**: `채널 1 확률 (파라미터)`

```
SCRIPT_REAL(
  "from tabpy_wholesale_cluster import get_channel_proba; return get_channel_proba(_arg1, _arg2, _arg3, _arg4, _arg5, _arg6, _arg7, _arg8)",
  [Fresh],
  [Milk],
  [Grocery],
  [Frozen],
  [Detergents_Paper],
  [Delicassen],
  [Region],
  [Select ML Model]
)
```

---

## 3. 시트에서 사용하는 방법

- **행/열에 아무 필드도 넣지 않고** 사용할 때:
  - 계산된 필드 `예측 채널 (파라미터)` / `채널 1 확률 (파라미터)`를 **텍스트**나 **단일 숫자**로 시트에 끌어다 놓으면 됩니다.
  - 6개 품목·Region·모델 선택 파라미터만 바꿔도 TabPy가 그때마다 한 건 예측해 줍니다.
- **모델 선택** 파라미터를 드롭다운으로 시트에 노출하면, XGBoost / RandomForest / CatBoost / LogisticRegression을 갈아끼워 가며 같은 입력으로 결과를 비교할 수 있습니다.

---

## 4. 군집 ID → 한글 이름 (Cluster ID 라벨)

TabPy `get_cluster` 결과(0~4)를 한글로 표시하려면, 아래 계산된 필드를 만들어 사용하세요.

**필드 이름(예)**: `군집 한글명` 또는 `Cluster 이름`

```
CASE [Cluster ID]
    WHEN 0 THEN '소규모 균형형'
    WHEN 1 THEN '대형 리테일·편의점형'
    WHEN 2 THEN '신선·냉동 중심형'
    WHEN 3 THEN '식료품·세제 강조형'
    WHEN 4 THEN '초소규모·냉동 위주형'
    ELSE '기타'
END
```

- 시트에서는 **숫자 필드 `Cluster ID` 대신** 이 `군집 한글명` 필드를 행/열/마크에 넣으면 한글로 표시됩니다.

---

## 5. TabPy 측 정리

- 사용하는 함수: **`get_channel`**, **`get_channel_proba`** (이미 배포되어 있음).
- 두 함수 모두 **마지막 인자 `ModelName`**을 받으며, 태블로에서 **파라미터(드롭다운)**로 넘기면 리스트로 올 수 있어, 코드에서 리스트면 첫 번째 값을 사용하도록 처리해 두었습니다.
- 6개 품목 + Region은 **파라미터 7개**, 모델 선택 **1개**로 총 8개 인자를 넘기면 됩니다.

이렇게 설정하면 6개 항목 매출액과 Region을 모두 매개변수로 두고, 4개 모델을 갈아끼워 쓸 수 있습니다.
